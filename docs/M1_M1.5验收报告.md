## 四、压测驱动修复的问题（真实 bug 记录）

1. **消息重试导致重复扣 DB 库存**（受理30/消耗90）：消费顺序改为「幂等→地址校验→扣库存→落库」；扣减前失败确认消费+回补分桶，扣减后失败回补 DB 再重试。
2. **MQ 发送失败窗口**：syncSend 失败回补分桶（实测触发过）。
3. **broker 通告内网 IP**：`brokerIP1=127.0.0.1` 根治（WSL 与 Docker 两代环境同款问题同款解）。
4. **压测脚本缺陷**：秒杀用户复用他人地址、成功分支变量名错误（NameError 污染记账）。
5. **WSL 僵尸 namesrv 抢占 9876**：应用连到旧进程导致 No route info——已随 WSL 清理根除。
