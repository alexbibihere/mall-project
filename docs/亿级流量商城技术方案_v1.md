# 亿级流量商城 高并发技术方案

> 生成日期：2026-09-19 ｜ 状态：M0 方案定稿（v2，替代秒杀单点方案）
> 定位：面试级亿级流量商城项目——秒杀方案已吸收为大促保障模块，不浪费
> 每个技术点都能讲出「为什么用它、不用它会怎样、什么量级才需要它」

## 1. 业务场景设定

类京东/淘宝综合商城：商品、搜索、购物车、交易、支付、营销、物流全链路。

- 规模指标（写进简历的数字）：
  - 日活用户 千万级，日 PV 10 亿+
  - SKU 亿级，订单表 日增千万级
  - 大促峰值 QPS 百万级（日常 5w+）
  - 核心链路（浏览/下单/支付）P99 < 200ms
  - 可用性 99.99%，零资损

## 3. 总体架构

```
用户 → CDN(静态页/图片) → Nginx → Gateway(鉴权/限流)
    → 业务微服务集群(商品/搜索/购物车/交易/库存/营销...)
    → 中间件(Redis多级缓存 / RocketMQ削峰 / ES检索)
    → 数据层(MySQL分库分表 / ClickHouse归档 / MinIO)
基础设施: K8s + Prometheus + SkyWalking + ELK
```

## 4. 微服务拆分（DDD 领域划分）

| 服务 | 职责 | 高并发手段 |
|---|---|---|
| 商品中心 | 商品/类目/SKU | 多级缓存 + 静态化 + CDN |
| 搜索服务 | 商品检索 | ES 集群 + 索引滚动 + DB↔ES 同步（MQ/Canal） |
| 购物车 | 加购/结算 | Redis hash 存储，不落库 |
| 交易中心 | 订单创建/状态机 | MQ 异步化 + 分布式 ID + 分库分表 |
| 库存中心 | 扣减/回补 | Redis+Lua 预扣 + DB 乐观锁兜底 + 分桶 |
| 支付中心 | 支付/退款/回调 | 幂等 + 对账中心 + 延迟消息关单 |
| 营销中心 | 优惠券/满减/秒杀 | 大促秒杀模块（前方案整体吸收） |
| 用户中心 | 注册/登录/风控 | JWT + 黑名单 + 限购风控 |
| 物流/评价/消息 | 周边域 | MongoDB / 削峰消费 |
| 对账中心 | 资金/库存对账 | XXL-Job 定时 + 差异告警（零资损防线） |

## 5. 亿级流量八大技术专题

### ① 多级缓存与读链路加速
Caffeine(本地) → Redis(集群) → MySQL，命中率逐层兜底；商品详情页静态化 + CDN 卸载 90% 读流量；缓存三防（穿透=布隆+空值、击穿=逻辑过期+互斥、雪崩=随机 TTL）。

### ② 分库分表与海量订单
订单按 user_id 分片 16 库×64 表；**基因法**把 buyer 分片基因嵌入订单号，同一单 buyer/seller/订单号三维度都能查；历史订单冷热分离归档 ClickHouse；读写分离扛读。

### ③ 异步化与削峰
下单主链路只做「扣库存预占 + 发事务消息」，落库/发券/通知全部异步；RocketMQ 事务消息保证本地事务与消息原子性；延迟消息做超时未支付关单回补。

### ④ 数据一致性与零资损
本地消息表（主）vs Seata AT/TCC（对比讲）；消费幂等（唯一索引+setnx）；对账中心 T+1 资金对账 + 实时库存对账，差异即告警——「零资损」的底气在兜底不在链路。

### ⑤ 高可用四板斧
限流（网关 Redis+Lua 滑动窗口 + Sentinel）、熔断降级（弱依赖可降：推荐/评价）、隔离（舱壁模式：线程池/连接池按域隔离）、预案与故障演练（混沌工程思路）。

### ⑥ 大促保障（秒杀模块）
前版秒杀方案整体吸收：漏斗削峰、库存分桶、防超卖三层防线、热点预热、全链路压测（流量染色）出容量数据。

### ⑦ 海量数据治理
埋点走 Kafka → ClickHouse；评价/IM 走 MongoDB；ES 按天索引 + 别名滚动；订单归档 XXL-Job 分批搬运。

### ⑧ 异地多活（设计亮点，进阶）
同城双活起步 → 单元化（用户维度分单元）→ 异地容灾；面试讲设计权衡与成本，不必实机搭建。

## 6. 面试考点 ↔ 项目模块映射

| 高频考点 | 项目落点 |
|---|---|
| 分库分表 | 订单 16×64 + 基因法 + 非分片键查询异构索引 |
| 缓存一致性 | 先更 DB 再删缓存 + 延迟双删 + Canal 对比 |
| 消息不丢不重 | 事务消息 + 消费幂等 + 死信人工兜底 |
| 分布式事务 | 本地消息表（主）vs Seata TCC（对比） |
| 分布式 ID | Leaf 段号 vs 雪花，时钟回拨应对 |
| 限流算法 | 计数器/漏桶/令牌桶/滑动窗口实现对比 |
| 热点 key | hotkey 探测 + Caffeine 本地扛 |
| 冷热分离/归档 | 订单归档 + ClickHouse 查询卸载 |
| 虚拟线程 | 读链路 I/O 密集场景开启与压测对比 |

## 7. 里程碑

- **M1** 单体跑通：商品 + 购物车 + 下单 + 支付(mock) 核心链路，JMeter 基线
- **M2** 微服务化：拆服务 + 多级缓存 + MQ 异步 + ES 搜索，压测对比
- **M3** 分布式化：分库分表 + 对账中心 + 监控大盘 + 全链路追踪
- **M4** 大促保障：秒杀模块 + 全链路压测 + 预案 + 异地多活设计文档

每阶段产出一版压测数据（QPS / P99 / 错误率），简历数字全部有据可查。
