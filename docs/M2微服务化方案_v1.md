# M2 微服务化方案（v1 规划稿）

> 日期：2026-09-20 ｜ 前置：M1+M1.5 已验收（commit 2854dbe），代码基线冻结于 main
> 目标：单体 → 微服务，引入「亿级流量规模配套」第一梯队（注册中心/网关/搜索/配置中心）

## 1. 服务拆分（第一批，从当前单体切出）

| 服务 | 模块来源 | 端口 | 说明 |
|---|---|---|---|
| mall-gateway | WebConfig 拦截器/JWT 校验上移 | 9000 | Spring Cloud Gateway，路由+全局鉴权+限流 |
| mall-user | com.mall.user | 8101 | 用户+地址 |
| mall-product | com.mall.product | 8102 | 商品+库存+多级缓存 |
| mall-cart | com.mall.cart | 8103 | 购物车（纯 Redis） |
| mall-order | com.mall.order + seckill 消费端 | 8104 | 交易+秒杀消费者 |
| mall-seckill | com.mall.seckill 生产端 | 8105 | 秒杀受理（Lua 预扣+发消息） |
| common | com.mall.common | - | 公共件（Result/注解/切面/工具） |

依赖关系：gateway → 各业务服务；seckill → (MQ) → order；cart/order → product(Feign 查商品)。

## 2. 新增技术栈

| 件 | 选型 | 版本锚点 | 用途 |
|---|---|---|---|
| 注册/配置中心 | Nacos | 2.4.x（Docker） | 服务发现 + 配置集中管理 |
| 网关 | Spring Cloud Gateway | SCA 2023.0.x | 统一入口/限流/灰度 |
| RPC | OpenFeign + LoadBalancer | 同上 | 服务间调用（订单查商品价） |
| 搜索 | Elasticsearch 8.x（Docker）+ IK 分词 | 8.14 | 商品检索/过滤聚合/搜索建议 |
| 同步 | MQ 广播刷新 + Canal 预留 | - | DB→ES 双方案，M2 先 MQ 后 Canal |
| 熔断限流 | Sentinel（替换自研注解） | 1.8.x | 规则中心+控制台 |
| 事务 | Seata AT（订单-库存跨服务） | 2.x | 对比本地消息表讲 |

## 3. 里程碑（M2 内部）

- M2.1：父 pom 聚合工程 + Nacos Docker + 各服务注册发现 + Gateway 路由（冒烟回归全链路）
- M2.2：OpenFeign 拆链（order→product）+ Sentinel 限流迁移 + Seata 试点（下单扣库存）
- M2.3：ES 商品搜索全链路（索引/同步/检索/聚合/建议）+ mall_bench 扩 ES 冒烟
- M2.4：压测对比报告（单机 8080 直压 vs 网关链路；缓存/秒杀指标回归）

## 4. 风险与对策

- 拆分期双跑：单体(8080)保留可切回，网关灰度路由
- Feign 级联超时：读链路 800ms 熔断降级（功能清单 3.1 既定）
- ES 内存：Windows 机器给 ES 容器 1G heap，单节点先跑
- 版本线：Spring Cloud 2023.0.x + SCA 2023.0.x + Boot 3.2.x~3.5.x 兼容矩阵查表后再定版

## 5. 验收标准（延续 M1 标准）

- 全链路冒烟经网关 12/12 通过
- ES 检索冒烟（写入→同步→检索→聚合→建议）新增用例全过
- 零超卖回归 ✓；缓存热读 QPS 不低于单机版 80%
- Sentinel 规则命中可视化；Seata 下单回滚演示可复现
